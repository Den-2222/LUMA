# 💰 Облік грошей — Telegram-бот + Mini App

Особистий облік доходів і витрат у Telegram. Дві частини, одна база:

- **Бот** — швидке додавання записів кнопками або текстом (`250 продукти`). Працює будь-де, нічого хостити не треба.
- **Mini App** — повноекранний застосунок усередині Telegram: дашборд, кругова діаграма по категоріях, графік по днях, історія, ліміти.

Дані лежать в одному файлі SQLite. Доступ — за списком Telegram ID, тобто бот приватний.

---

## Швидкий старт

```bash
./run.sh setup          # venv, залежності, збірка фронтенду, .env
# впиши BOT_TOKEN у .env
./run.sh bot            # запуск бота
```

Токен: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюй рядок виду `123456:AA...`.

Після цього бот уже повністю робочий: кнопки, швидкий ввід, статистика, ліміти, експорт CSV.
**Mini App із графіками — окремий крок нижче**, бо він потребує HTTPS-адреси.

### Обмежити доступ друзям

1. Запусти бота з порожнім `ALLOWED_USERS` і напиши йому `/start`.
2. Дізнайся свій ID (наприклад, у [@userinfobot](https://t.me/userinfobot)) і ID друзів.
3. Впиши їх у `.env` і перезапусти:

```env
ALLOWED_USERS=11111111,22222222,33333333
ADMIN_USERS=11111111
```

Усі, кого нема в списку, отримають «Цей бот приватний» і не створять у базі нічого.

## Mini App (екран із графіками)

Telegram відкриває Mini App лише з **публічного HTTPS-домену** — `localhost` не підійде.

### Варіант A — з ноутбука через тунель (безкоштовно, 2 хвилини)

```bash
./run.sh server                        # термінал 1: API + фронтенд на :8080
cloudflared tunnel --url http://localhost:8080   # термінал 2: видасть https://xxx.trycloudflare.com
```

Отриману адресу впиши у `.env` як `WEBAPP_URL` і перезапусти бота. Кнопка «📱 Застосунок» з'явиться в меню.

> Безкоштовний тунель дає **нову адресу при кожному запуску** — доведеться щоразу оновлювати `WEBAPP_URL`. Для постійного користування краще варіант B.

### Варіант B — свій сервер (працює 24/7, постійна адреса)

Один прогін ставить усе: бота, API, nginx, TLS, автозапуск і щоденні бекапи.

```bash
sudo ./deploy/install.sh --domain groshi.твійдомен --token 123456:AA... --allow 111111,222222
```

Покроково для DigitalOcean (який дроплет, DNS, фаєрвол), оновлення, відновлення з бекапу й розбір типових помилок — у [deploy/README.md](deploy/README.md).

## Як користуватись

**Швидкий ввід текстом** (найшвидше — 5 секунд):

| Пишеш | Що вийде |
|---|---|
| `250 продукти` | витрата 250 ₴, категорія «Продукти» |
| `таксі 180` | порядок слів не важливий |
| `+45000 зарплата` | плюс спереду = дохід |
| `1 250,50 оренда` | копійки через кому |
| `ліміт продукти 8000` | ліміт на місяць; бот попередить на 80% |
| `категорія Спорт` | своя категорія витрат (`категорія+ Оренда` — доходів) |

Категорію бот вгадує за ключовими словами. Не вгадав — запропонує обрати кнопкою.

**Кнопки:** ➖ Витрата / ➕ Дохід (ввід у два тапи) · 📊 Статистика · 📜 Останні · ⚙️ Ще.
**Команди:** `/start`, `/stats`, `/history`, `/export`, `/help`.

## Структура

```
app/         спільне ядро: конфіг, SQLite, запити, парсер тексту, формат грошей
bot/         aiogram-бот: клавіатури, хендлери, рендер текстових екранів
server/      FastAPI: API для Mini App + перевірка підпису Telegram
webapp/      React + TypeScript + Vite (Mini App, ~53 КБ gzip)
deploy/      systemd-юніти, nginx, скрипт установки на сервер
tests/       інтеграційні тести бота і перевірки безпеки
```

## Тести

```bash
./run.sh test
```

- `tests/test_auth.py` — підроблений підпис, прострочені дані, підміна `user_id`.
- `tests/test_bot_flow.py` — 12 сценаріїв: від `/start` до видалення запису й відмови сторонньому. Гоняє справжні апдейти через диспетчер із підробленою сесією Telegram, мережа не потрібна.

## Безпека і дані

- Кожен запит Mini App несе `initData`, підписаний токеном бота; сервер перевіряє HMAC-SHA256 і відкидає прострочене (>24 год). Без цього будь-хто міг би підставити чужий `user_id`.
- `DEV_USER_ID` обходить перевірку — тільки для локальної розробки, у бойовому `.env` має бути порожнім.
- Суми зберігаються цілими числами в копійках — без похибок float.
- Уся база — один файл. Бекап: `./run.sh backup` (на сервері — щодня автоматично, 14 останніх копій). Експорт для себе: `/export` у боті (CSV відкривається в Excel).
